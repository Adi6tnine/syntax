# Setup Instructions

Follow these steps to get the project running:

## Step 1: Install Dependencies

Open your terminal in the `ai-agents-event` folder and run:

```bash
npm install
```

This will install:
- React & React DOM
- React Router DOM (for routing)
- Lucide React (for icons)
- Tailwind CSS (for styling)
- Vite (build tool)

## Step 2: Start Development Server

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Step 3: Build for Production

```bash
npm run build
```

## Step 4: Preview Production Build

```bash
npm run preview
```

## Troubleshooting

If you encounter any issues:

1. Make sure you're in the `ai-agents-event` directory
2. Delete `node_modules` and `package-lock.json`, then run `npm install` again
3. Make sure you have Node.js 18+ installed
